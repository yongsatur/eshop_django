# Интернет-магазин на Django

Первый интернет-магазин, созданный на **Django**.

## О проекте

**Eshop Django** — это полнофункциональный веб-сайт интернет-магазина, разработанный в качестве учебного проекта для изучения возможностей фреймворка Django.

Проект демонстрирует реализацию ключевых функций веб-приложения, включая управление пользователями, каталогом товаров, корзиной покупок и процессом оформления заказа.

## Основной функционал

### Пользователи 

*   Регистрация и авторизация пользователей;
*   Изменение личной информации пользователя;
*   Изменение пароля пользователя.

### Каталог и товары

*   Просмотр каталога товаров;
*   Фильтрация товаров по категориям;
*   Сортировка товаров по цене;
*   Поиск товаров по названию;
*   Просмотр детальной информации о товаре.

### Корзина и заказы

*   Добавление товаров в корзину из каталога и со страницы товара с уведомлением;
*   Оформление заказа и выбор способа доставки;
*   Просмотр личного кабинета с историей совершенных заказов.

### Администрирование

*   Полнофункциональная админ-панель Django;
*   Управление товарами, категориями, характеристиками товаров и другими сущностями.

## Стек технологий

*   **Backend:** Python, Django;
*   **База данных:** SQLite.
