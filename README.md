# Интернет-магазин на Django

Первый интернет-магазин, созданный на **Django**.

## О проекте

**AssorTEA** – это интернет-магазин для продажи чайной продукции, разработанный в качестве учебного проекта для изучения возможностей фреймворка Django.

Проект демонстрирует реализацию ключевых функций веб-приложения, включая управление пользователями, каталогом товаров, корзиной покупок и процессом оформления заказа.

## Основной функционал

**Пользователи:**

$`\color{yellow}*`$ Регистрация и авторизация пользователей;<br>
$`\color{yellow}*`$ Изменение личной информации пользователя;<br>
$`\color{yellow}*`$ Изменение пароля пользователя.

**Каталог и товары:**

$`\color{yellow}*`$ Просмотр каталога товаров;<br>
$`\color{yellow}*`$ Фильтрация товаров по категориям;<br>
$`\color{yellow}*`$ Сортировка товаров по цене;<br>
$`\color{yellow}*`$ Поиск товаров по названию;<br>
$`\color{yellow}*`$ Просмотр детальной информации о товаре.

**Корзина и заказы:**

$`\color{yellow}*`$ Добавление товаров в корзину из каталога и со страницы товара с уведомлением;<br>
$`\color{yellow}*`$ Оформление заказа и выбор способа доставки;<br>
$`\color{yellow}*`$ Просмотр личного кабинета с историей совершенных заказов.

**Администрирование:**

$`\color{yellow}*`$ Полнофункциональная админ-панель `Django` ;<br>
$`\color{yellow}*`$ Управление товарами, категориями, характеристиками товаров и другими сущностями.
